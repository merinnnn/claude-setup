---
name: debug
description: Systematic debugging workflow with minimal context usage.
---

1. Reproduce the failure.
2. Capture only useful evidence.
3. Form 2-3 hypotheses.
4. Test hypotheses with targeted searches/commands.
5. Identify root cause.
6. Make the smallest fix.
7. Run focused tests.
8. Run broader verification.
9. Checkpoint only after verification passes.

Do not repeatedly dump large logs.
