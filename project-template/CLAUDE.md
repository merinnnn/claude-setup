# Project instructions

## Workflow
For substantial work:
1. inspect
2. plan
3. implement
4. verify
5. checkpoint commit
6. independent review
7. fix findings
8. verify again

## Git
- Work on a dedicated feature branch.
- Never directly modify main/master for feature work.
- Check status and diff before commits.
- Checkpoint commits must represent verified milestones.

## Verification
Configure the real commands in:
`scripts/verification.ps1`

## Context
Keep only every-session project facts here. Put procedures in Skills and durable cross-project knowledge in Obsidian.
